Instrução de uso:
O sistema pede um conjunto de cinco chaves ao usuário. Após inserir o nome da primeira chave, o sistema pede um valor para esta chave, que precisa ser um valor
coerente, isto é, um input real. Usando um laço for simples com range, a função principal associa o valor a chave.
Depois de repetir o processo anterior cinco vezes, o while termina e o bloco de display no fundo do código chama as funçôes e mostra ao usuário um relatório, contendo um índice de valor total, produto mais caro emais barato. Somente cinco produtos podem ser cadastrados, como requisitado no escopo.
